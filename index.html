BPUT Results API Documentation

Welcome to the BPUT Results API! This API provides access to student results, details, and SGPA information from BPUT (Biju Patnaik University of Technology). Below are the available endpoints and how to use them.

Note: Replace placeholders like <rollno>, <semid>, <session>, and <dob> with actual values.

1. Student Details

Fetch student details using their roll number.

GET /details?rollno=<rollno>

Example Request:

GET /details?rollno=1234567890

Example Response:

{ "studentName": "John Doe", "rollNo": "1234567890", "program": "B.Tech in Computer Science", "college": "Some College" }

2. Student Results

Fetch subject-wise results for a student. You can also request the results in HTML format by adding the html=true parameter.

GET /results?rollno=<rollno>&semid=<semid>&session=<session>&html=<true|false>

Parameters:

  • rollno: The student's roll number (required).
  • semid: The semester ID (default: 4).
  • session: The exam session (default: E24).
  • html: Set to true to get results in HTML format (optional).

Example Request (JSON):

GET /results?rollno=1234567890&semid=4&session=E24

Example Response (JSON):

[ { "subjectCODE": "CS101", "subjectName": "Introduction to Computer Science", "subjectCredits": "4", "grade": "A" }, { "subjectCODE": "MA101", "subjectName": "Mathematics I", "subjectCredits": "3", "grade": "B" } ]

Example Request (HTML):

GET /results?rollno=1234567890&semid=4&session=E24&html=true

Example Response (HTML):

<!-- Rendered HTML page with student details, results, and SGPA -->

3. Exam Information

Fetch exam-related information for a student.

GET /examinfo?rollno=<rollno>&dob=<dob>&session=<session>

Example Request:

GET /examinfo?rollno=1234567890&dob=2000-01-01&session=E24

Example Response:

{ "examName": "End Semester Examination", "examDate": "2023-12-15", "status": "Completed" }

4. SGPA Details

Fetch the SGPA (Semester Grade Point Average) for a student.

GET /sgpa?rollno=<rollno>&semid=<semid>&session=<session>

Example Request:

GET /sgpa?rollno=1234567890&semid=4&session=E24

Example Response:

{ "sgpa": "9.2" }

5. All Sessions

Fetch a list of all available exam sessions.

GET /allsession

Example Response:

[ { "name": "Odd-(2024-25)", "shortCode": "O25" }, { "name": "Supplementary 2023-24", "shortCode": "S24" }, { "name": "Even-(2023-24)", "shortCode": "E24" } ]

6. Combined Data

Fetch student details, subject results, and SGPA in a single request.

GET /combined?rollno=<rollno>&semid=<semid>&session=<session>

Example Request:

GET /combined?rollno=1234567890&semid=4&session=E24

Example Response:

{ "studentDetails": { "studentName": "John Doe", "rollNo": "1234567890", "program": "B.Tech in Computer Science", "college": "Some College" }, "subjectResults": [ { "subjectCODE": "CS101", "subjectName": "Introduction to Computer Science", "subjectCredits": "4", "grade": "A" }, { "subjectCODE": "MA101", "subjectName": "Mathematics I", "subjectCredits": "3", "grade": "B" } ], "sgpaDetails": { "sgpa": "9.2" } }
